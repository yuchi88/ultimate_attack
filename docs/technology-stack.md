## まとめ

このアプリは、React + TypeScript + Vite を中心にしたフロントエンド単体アプリです。バックエンドやデータベースは持たず、Web カメラ映像をブラウザ内で MediaPipe によって解析し、その結果をもとにゲーム判定と Canvas 演出を行います。インフラ面では、ローカル開発は Node.js / npm / Vite、本番配信は静的ファイル配信を前提にできる構成です。
